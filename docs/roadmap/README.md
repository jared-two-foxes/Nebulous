# Nebulous Roadmap

This directory holds longer-horizon product and architecture planning for Nebulous.

Linear is intentionally reserved for **near-term executable implementation projects**. Roadmap items here should not be mirrored into Linear as implementation tickets until they become current work.

## Promotion rule

When a roadmap area becomes current:

1. Review the relevant code on `master`.
2. Update or write the design/spec for the desired outcome.
3. Create a finite Linear project with a clear end condition.
4. Generate fresh implementation tickets from the current codebase.
5. Close the project when that outcome is delivered.

Do not reactivate old implementation tickets verbatim simply because a roadmap item becomes interesting again.
